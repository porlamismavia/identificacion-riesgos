# Identificación de Riesgos Laborales — UGT Castilla-La Mancha

Aplicación web progresiva (PWA) para la realización de fichas de identificación de riesgos laborales en visitas a centros de trabajo, desarrollada para uso interno de los delegados/as de personal y de prevención de UGT Castilla-La Mancha.

|------|--------|-----------|
| 49 | Transporte Terrestre y por Tubería | 5 |
| 52 | Almacenamiento y Actividades Anexas al Transporte | 6 |

## Funcionalidades

- Formulario de datos de la visita (empresa, centro, responsable, delegado/a…)
- Checklist interactivo por secciones con desplegables (SÍ / NO / N/A)
- Campo de observaciones por cada riesgo detectado
- Contador de progreso en tiempo real
- Resumen de incidencias y acciones prioritarias
- Exportación del informe completo a PDF
- Instalable como PWA en Android e iOS

## Base legal

Elaborado conforme a:
- **Ley 31/1995**, de 8 de noviembre, de Prevención de Riesgos Laborales
- **RD 39/1997**, de 17 de enero, por el que se aprueba el Reglamento de los Servicios de Prevención

## Uso

La aplicación es de uso exclusivo interno para delegados/as de personal y de prevención afiliados a UGT Castilla-La Mancha.

## Tecnología

Aplicación de página única (SPA) desarrollada en HTML5, CSS3 y JavaScript puro, sin dependencias de servidor. Exportación PDF mediante [jsPDF](https://github.com/parallax/jsPDF).
